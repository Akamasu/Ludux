# Actifs et marques

Sauf indication contraire ci-dessous, les actifs originaux distribués dans le dépôt Ludux sont placés sous la même licence `GPL-3.0-only` que le code source.

## Actifs Ludux

- `public/ludux-logo.png` : identité visuelle créée pour Ludux par Akamasu.
- `public/favicon.svg` : icône originale Ludux.
- `public/assets/open-book-pages-ludux.webp` : illustration originale créée pour la vue livre de Ludux à l’aide de l’outil de génération d’images intégré à Codex, puis détourée localement.
